# Внутренний разбор HTTP/1

`wire.bit` — заготовка для нового сетевого транспорта. Она **пока не
подключена** к `fetch`, `post` и `download`: на macOS и Linux эти операции
всё ещё используют `curl`. Модуль не открывает соединения, не выполняет TLS,
не разбирает URL и не следует перенаправлениям.

Разбор выполняется последовательно, без общего состояния потоков. Владелец
создаёт состояние через `http_wire_new()` и после использования освобождает
его через `http_wire_free()`. Каждую полученную порцию передают в
`http_wire_feed(state, input, count, output)`; буфер `output` должен вмещать
не меньше `count` байт. Возвращается число записанных байт тела или `-1`
при ошибке; после ошибки содержимое выходного буфера использовать нельзя.
При чистом закрытии соединения нужно вызвать `http_wire_eof(state)` и
считать ответ успешным только при `true`. Код ответа хранится по смещению 8
в состоянии (`state >> read(8)`), а `http_wire_location(state)` возвращает
значение заголовка `Location` последнего ответа. Повторный `Location`
отклоняется. Вызывающая сторона отвечает за
освобождение своих буферов и безопасное сохранение данных во временный файл.

Поддержаны HTTP/1.0 и HTTP/1.1, промежуточные ответы, тело заданной длины,
тело до закрытия соединения и chunked с завершающими заголовками. Дубликаты
`Content-Length`, сочетание `Content-Length` и `Transfer-Encoding`, другие
кодировки передачи, незавершённые заголовки или тело отклоняются. Размер
строки ограничен 8192 байтами, суммарный размер заголовков — 65536 байтами.
Парсер рассчитан на ответы GET/POST, протоколы после `101` не поддерживаются.
