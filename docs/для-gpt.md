# Брифинг для GPT (тестировщик и направляющий языка bit)

Это точное состояние языка на сейчас. GPT не видит репозиторий, поэтому направляй,
опираясь на этот документ, а не на догадки. Клод (исполнитель) сверяет каждое
утверждение с кодом и вправе отклонить то, что неверно или против идентичности языка.

## Что такое bit

Язык, который должен быть легче Python, быстрее C++, безопаснее Rust. Компилятор
`bitc.bit` (~17k строк) написан на самом bit, собирает сам себя с нуля (без C, LLVM,
Python), печатает ассемблер ARM64/x86-64, линкует через `as`/`ld`. Кросс-компиляция:
macOS (arm64, x86-64), Linux (x86-64), Windows (x86-64).

## Что уже есть

- **Типы:** `num` (целое 64 бита), `dec` (дробное), `string` (UTF-8), `bool`,
  `mas` (массив), `bytes` (сырая память), `file`, `dir`, `conn`, `server`,
  `proc` (чужой процесс, Linux), `all` (тип выводится).
- **Синтаксис:** точка входа `host { }` (не `fn main`), функции `fn`, действия и
  присваивание через `do` / `ch`, цепочки `>>`, `keep`/`each` с `it`, `for … in`
  (массив или диапазон `a:b`), `while`, `if`/`else`, `break`/`next`,
  интерполяция строк `{…}`, комментарии `#`.
- **Операторы:** `+ - * / %`, сравнения, `and`/`or`/`not`, диапазон `a:b`.
  Битовые — методами: `shift_left`/`shift_right`/`bit_and`/`bit_or`/`bit_xor`/`bit_not`.
- **Методы:** строки (`sz`/`get`/срез/`num`/`lines`/`bytes`/`run`), массивы
  (`sz`/`get`/`add`/`set`/`ch`/`keep`/`each`/`find`/`has`/`sum`/`sort`/`join`),
  файлы и папки, `bytes` (`set`/`write`/`get`/`read`/`text`), `mem`, `os`, `term`,
  сеть (TCP/UDP/DNS/HTTP: `listen`/`accept`/`connect`/`udp`/`send`/`recv`/`ip`/
  `fetch`/`post`/`ping`/`download`), чтение/запись памяти чужих процессов (Linux).
- **Безопасность на этапе сборки:** границы массивов/строк доказываются (без
  рантайм-проверок), переполнение `num` и чтение пустой переменной ловятся при
  компиляции, типы проверяются.
- **Память:** авто-освобождение свежих временных строк; подсчёт ссылок начат
  (заголовок-счётчик в рантайме, тип `bytes`); полная эмиссия inc/drop и дисциплина
  алиасинга — ещё не доделаны.
- **Рантайм:** опирается на libc (`malloc`/`printf`) и системные вызовы хоста —
  **не freestanding** (пока нельзя писать ядро/ОС без хоста).
- **Проверка:** 117 тестов, самосборка сходится на обеих архитектурах.

## Чего нет (честные пробелы)

Структуры (записи), enum/варианты, модули/несколько файлов, обработка ошибок
(рантайм-ошибка = выход), словари (map/set), функции-значения, часть mas-операций
(`remove`/`insert`/`pop`/`first`/`last`), строковые (`split`/`trim`/`replace`/
`starts`/`ends`), математика (`sqrt`/`pow`/`abs`/`min`/`max`/`rand`), типизированный
`bytes` (u16/u32/float + endianness), потоки/async, время/даты, `const`, кортежи,
отладочная информация, пакетный менеджер, оптимизатор.

## Правила, которые нельзя нарушать (иначе фича отклоняется)

1. **Имена угадываются** — никаких асемблерно-сишных сокращений (было `shl` →
   стало `shift_left`).
2. **Свой облик, не C/C++/Rust** — опора на свой словарь (`do`/`ch`/`>>`/`host`),
   но знакомый синтаксис (скобки, `;`) ломать без нужды не надо.
3. **Всё видно и последовательно** — действия через `do`/`ch`, значения просто
   считаются.
4. **Безопасность на этапе сборки не ослабляется** новыми фичами.
5. **Самосборка остаётся зелёной**, каждая фича выразима на самом bit.
6. **FFI (вызов C) — вне стола по решению:** смысл языка в том, что вся цепочка
   своя. Предлагать FFI не нужно.

## Две цели (держим обе)

- **Цель 1 — юзабельный язык общего назначения.** Порядок: дисциплина алиасинга
  (дорешать refcount) → обработка ошибок → структуры → map → функции-значения →
  модули; плюс лёгкая корзина (mas-операции, строки, математика, типизированный
  `bytes`).
- **Цель 2 — дорасти до «на bit можно писать ОС».** Это отдельная дорожка поверх
  цели 1: freestanding-рантайм (без libc и системных вызовов хоста), bare-metal цель
  (загрузка, MMIO, прерывания), способ вписать сырые инструкции (inline asm), память
  без опоры на авто-подсчёт в ядровых местах.

## О чём просьба к GPT

Задавай приоритеты и предлагай **конкретные программы-тесты**, которые вскроют
реальные пробелы (например: «напиши на bit парсер JSON» обнажит отсутствие структур,
map и обработки ошибок). Говори, к какой из двух целей двигает директива. Помни про
правила выше — предложения, которые их нарушают, будут отклонены с объяснением.
